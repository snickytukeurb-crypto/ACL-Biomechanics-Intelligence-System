# ACL Biomechanics Intelligence System

เครื่องมือประเมินความเสี่ยงการบาดเจ็บเอ็นไขว้หน้าหัวเข่า (Anterior Cruciate Ligament)
จากวิดีโอหรือกล้องเว็บแคม ด้วยการตรวจจับท่าทางแบบไม่ต้องติดเซนเซอร์

ระบบอ่านตำแหน่งสะโพก เข่า และข้อเท้าจากภาพด้วย MediaPipe Pose แล้วแปลงเป็นตัวแปร
ทางชีวกลศาสตร์สี่ตัว คือมุมข้อเข่า มุมเข่าเบี่ยงเข้าด้านใน ความเร็วเชิงมุม และความเร่งเชิงมุม
จากนั้นรวมเป็นดัชนีความเสี่ยงค่าเดียวในช่วง 0-100 พร้อมแสดงผลแบบเรียลไทม์

## ความต้องการของระบบ

| สิ่งที่ต้องมี | เหตุผล |
|---|---|
| **Python 3.12** | MediaPipe ยังไม่มีตัวติดตั้งสำหรับ 3.13 ขึ้นไป |
| Google Chrome | ใช้แปลงรายงานเป็น PDF |
| ffmpeg | ใช้ย่อขนาดวิดีโอผลลัพธ์ |

Chrome และ ffmpeg ไม่มีก็ใช้งานส่วนอื่นได้ตามปกติ ระบบจะแจ้งเตือนเฉพาะฟีเจอร์ที่ใช้ไม่ได้

เท่านั้น **ไม่มีผลต่อค่าความเสี่ยง** จากนั้นเลือกอัปโหลดคลิปหรือใช้กล้องเว็บแคม แล้วกดเริ่มวิเคราะห์

## ผลลัพธ์ที่ได้

**ระหว่างวิเคราะห์** ป้ายสีสัญญาณไฟจราจรขนาดใหญ่บอกระดับ Low / Moderate / High
แบบเรียลไทม์ ทั้งบนหน้าเว็บและบนภาพวิดีโอเอง พร้อมค่าตัวแปรทั้งสี่ของขาทั้งสองข้าง

**เมื่อวิเคราะห์เสร็จ**

- **เฟรมวิกฤต (Critical Frame)** — เฟรมที่มุมข้อเข่าน้อยที่สุด ซึ่งเป็นจังหวะที่รับแรงมากที่สุด
  ใช้ค่าดัชนี ณ เฟรมนี้เป็นผลของการทดสอบหนึ่งครั้ง
- **ตารางสรุป** แยกขาซ้าย ขาขวา และรวม
- **กราฟ** ดัชนีความเสี่ยงและมุมข้อเข่าตลอดช่วงที่วิเคราะห์
- **วิดีโอผลลัพธ์** ทุกเฟรมมีค่าตัวแปรฝังอยู่ในภาพ เลือกความละเอียดและดาวน์โหลดได้
- **ตารางรายเฟรม** ครบทุกแถว
- **ไฟล์ CSV** และ **รายงาน PDF** หน้าเดียวจบ

## แบบจำลองที่ใช้

```
R = 100 · [ 0.25·f(θ) + 0.35·f(γ) + 0.20·f(ω) + 0.20·f(α) ]

f(θ) = (180 − θ)/180    f(γ) = γ/30    f(ω) = |ω|/300    f(α) = |α|/1500
ทุกพจน์ถูกจำกัดอยู่ในช่วง [0, 1]

Low: R < 25     Moderate: 25 ≤ R < 50     High: R ≥ 50
```

โดย θ คือมุมข้อเข่า (180° = ขาเหยียดตรง), γ คือมุมเข่าเบี่ยงเข้าด้านในบนระนาบหน้า,
ω และ α คืออนุพันธ์อันดับหนึ่งและสองของมุมเทียบกับเวลา

`tests/test_risk.py` ตรึงค่าน้ำหนัก ค่าอ้างอิง และเกณฑ์แบ่งระดับไว้ทั้งหมด
ถ้าแก้สมการแล้วชุดทดสอบไม่ผ่าน แปลว่าแบบจำลองเปลี่ยนไปแล้ว

## รายละเอียดการคำนวณที่ควรทราบ

**มุมเข่าเบี่ยงเข้าด้านใน (γ)** วัดจากระยะตั้งฉากของข้อเข่าถึงแนวสะโพก-ข้อเท้าบนระนาบหน้า
ได้ 0 องศาเมื่อข้อเข่าอยู่บนแนวพอดี วิธีนี้ให้ค่าที่ไม่ขึ้นกับว่าเข่างอลึกเท่าใด ต่างจากการวัดมุม
ระหว่างต้นขากับหน้าแข้งตรง ๆ ซึ่งจะปนค่าการงอเข่าเข้ามาด้วยจนแยกกันไม่ออกเมื่อย่อตัวลึก

**การกรองสัญญาณ** ω และ α มาจากการหาอนุพันธ์เชิงตัวเลขหนึ่งและสองครั้ง ซึ่งขยาย
สัญญาณรบกวนของการตรวจจับแบบทวีคูณ ระบบจึงกรองทั้งมุมและความเร็วเชิงมุมด้วย
ค่าเฉลี่ยเคลื่อนที่ก่อนหาอนุพันธ์ วัดขณะผู้ทดสอบยืนนิ่ง (ค่าที่ถูกต้องควรเป็นศูนย์) การกรอง
ลด |α| ที่เป็นสัญญาณรบกวนล้วนจากราว 1100 เหลือราว 100 องศา/วินาที²

ปรับขนาดหน้าต่างได้ที่ `SMOOTHING_WINDOW` หัวไฟล์ `app.py` **ตั้งเป็น 1 คือปิดการกรอง**

**ป้ายระดับความเสี่ยงแบบเรียลไทม์** ใช้มัธยฐานของ R ในช่วงสั้น ๆ กันป้ายกะพริบ แล้วค้าง
ค่าสูงสุดไว้สองวินาที เพราะจังหวะเสี่ยงจริงตอนลงสู่พื้นกินเวลาเพียงราว 0.1 วินาที ซึ่งสั้นเกินกว่า
คนจะอ่านทัน ค่าที่ป้ายแสดงใช้เพื่อการมองเห็นเท่านั้น **ผลสรุปและไฟล์ CSV ใช้ค่ารายเฟรมดิบ**

## โครงสร้างโค้ด

`app.py` เป็นส่วนติดต่อผู้ใช้อย่างเดียว การคำนวณทั้งหมดอยู่ในแพ็กเกจ `acl/`

| ไฟล์ | หน้าที่ |
|---|---|
| `acl/risk.py` | สมการดัชนีความเสี่ยง ค่าน้ำหนัก และเกณฑ์แบ่งระดับ |
| `acl/biomech.py` | มุมข้อเข่า มุมเบี่ยง อนุพันธ์เชิงตัวเลข ตัวกรองค่าเฉลี่ยเคลื่อนที่ |
| `acl/pose.py` | ห่อหุ้ม MediaPipe Pose และวาดโครงขาลงบนภาพ |
| `acl/session.py` | ผลรายเฟรม เลือกเฟรมวิกฤต ส่งออก CSV |
| `acl/report.py` | ตารางสรุป กราฟ และการสร้างรายงาน PDF |
| `acl/video.py` | เขียนวิดีโอผลลัพธ์และย่อขนาด |

การแปลง PDF ใช้ Chrome แบบ headless เพราะการวางสระบน-ล่างและวรรณยุกต์ไทยต้องใช้
เอนจินจัดรูปอักษรที่ครบถ้วน ซึ่งไลบรารีสร้าง PDF ทั่วไปทำได้ไม่ถูกต้อง ส่วนข้อความบนกราฟ
และบนวิดีโอเป็นภาษาอังกฤษ เพราะ matplotlib และ OpenCV ไม่รองรับการจัดรูปอักษรไทยเช่นกัน

## ข้อควรทราบเรื่องการถ่ายวิดีโอ

γ วัดบนระนาบหน้า จึงต้องถ่าย **ด้านหน้า** ผู้ทดสอบ ไม่ใช่ด้านข้าง ให้เห็นสะโพก เข่า และ
ข้อเท้าครบทั้งตัวตลอดการเคลื่อนไหว ในที่ที่แสงเพียงพอ ระยะประมาณ 2-3 เมตร

เฟรมที่ระบบมองเห็นข้อต่อไม่ชัดพอจะถูกข้าม ไม่นำเข้าสู่การคำนวณ

โหมดกล้องเว็บแคมบันทึกวิดีโอผลลัพธ์ด้วยอัตราเฟรมที่กล้องแจ้งมา ถ้าเครื่องประมวลผลได้ช้ากว่านั้น
วิดีโอที่ได้จะเล่นเร็วกว่าความเป็นจริงเล็กน้อย ส่วนคลิปที่อัปโหลดไม่มีปัญหานี้

## ขอบเขตการใช้งาน

เครื่องมือนี้เป็นระบบคัดกรองเชิงปริมาณจากภาพ ไม่ใช่เครื่องมือวินิจฉัยทางการแพทย์
